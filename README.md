# Sprint_7

Проект автотестов для API учебного сервиса «Яндекс Самокат».

Тестируемый сервис: https://qa-scooter.praktikum-services.ru/

## Что протестировано

### Создание курьера

Проверки:
- курьера можно создать;
- нельзя создать двух одинаковых курьеров;
- для создания курьера нужно передать обязательные поля;
- успешный запрос возвращает код 201;
- успешный запрос возвращает тело ответа {"ok": true};
- если не передать обязательное поле, возвращается ошибка;
- если создать курьера с логином, который уже есть, возвращается ошибка.

Файл с тестами:
tests/test_create_courier.py

### Логин курьера

Проверки:
- курьер может авторизоваться;
- для авторизации нужно передать обязательные поля;
- система возвращает ошибку, если неправильно указать логин или пароль;
- если обязательное поле пустое, запрос возвращает ошибку;
- если авторизоваться под несуществующим пользователем, запрос возвращает ошибку;
- успешный запрос возвращает id.

Файл с тестами:
tests/test_login_courier.py

### Создание заказа

Проверки:
- можно создать заказ с цветом BLACK;
- можно создать заказ с цветом GREY;
- можно создать заказ с двумя цветами: BLACK и GREY;
- можно создать заказ без указания цвета;
- тело успешного ответа содержит track.

Файл с тестами:
tests/test_create_order.py

### Список заказов

Проверки:
- в тело ответа возвращается список заказов.

Файл с тестами:
tests/test_order_list.py
